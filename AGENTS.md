# Правила работы агента

- Работай только внутри этого репозитория.
- Для каждой задачи создавай отдельную ветку.
- Не делай push в main.
- Не трогай .env и секреты.
- Перед завершением запускай: uv run pytest и uv run ruff check .
- Сначала покажи план, затем реализуй.
- Меняй минимум файлов, делай маленькие коммиты.
